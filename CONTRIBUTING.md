# Como colaborar com o PortfolioHUB

Obrigada pelo interesse em colaborar! Siga o fluxo abaixo.

## Fluxo de trabalho
1. Crie uma branch a partir da main, com um nome claro (ex.: feature/novo-projeto).
2. Faça suas alterações e registre com commits curtos e objetivos.
3. Abra um Pull Request descrevendo o que foi alterado e por quê.
4. Aguarde a revisão. Ajustes podem ser solicitados.
5. Após a aprovação, o Pull Request é mesclado (merge) na main.

## Padrão de mensagens de commit
- feat: nova funcionalidade ou novo projeto
- fix: correção de erro
- docs: alterações em documentação

## Regras
- A branch main é protegida: não é permitido apagá-la, reescrever o histórico nem alterá-la sem Pull Request.
- Nunca envie senhas, tokens, chaves ou dados pessoais sensíveis.
- Links externos devem usar rel="noopener noreferrer".

## Contato e segurança
Para reportar problemas de segurança, consulte o arquivo SECURITY.md.
